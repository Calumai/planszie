# 減脂陪跑 Mobile

Expo 版手機 app，給日常減脂紀錄使用。

## 使用方式

```bash
npm install
npm start
```

開啟後用手機的 Expo Go 掃 QR code。

## 目前功能

- 今天摘要：剩餘熱量、已吃熱量、蛋白質、碳水、運動消耗
- 飲食紀錄：餐別、描述、照片、快速估算、熱量計算機大按鈕、三大營養素
- 運動紀錄：運動類型、分鐘數、估算消耗
- 習慣分數：喝水、不喝含糖飲料、睡眠恢復、紀錄完成度
- AI 教練頁：根據今天資料給行動建議
- 本機儲存：資料存在手機本機
